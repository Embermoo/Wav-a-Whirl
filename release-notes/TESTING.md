# Tester checklist

Record your OS version, app version, audio output, and file types tested.

- Select a folder (include spaces and non-English characters in the path).
- Try WAV, MP3, FLAC, Ogg, Opus, M4A, AAC, and AIFF where available.
- Test normal delays and both delays set to zero.
- Pause during playback and during a delay; resume.
- Hard Stop, restart, and let a short session expire.
- Change volume during playback; test 0% and 100%.
- Compare loud/soft copies with balancing off and on.
- Pause/stop while balancing analyzes the folder.
- Check Spoiler mode, window resizing, and enlarged system text.
- Reopen to verify settings; verify no automatic playback.
- Try a missing/deleted file and an invalid audio file.
- Click Premium; close the message and continue using playback.

Build checks establish compilation only. Audible playback and device behavior
must be verified on each native platform before marking it supported.
